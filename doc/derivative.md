| Notation               | $f(x)$ derivative | $f(x, y, z)$ derivative with respect to $y$ |
| :--------------------- | :---------------- | :------------------------------------------ |
| **Lagrange**           | $f'(x)$           | $f_y(x, y, z)$                              |
| **Leibniz**            | $\frac{df}{dx}$   | $\frac{\partial f}{\partial y}$             |
| **D-Notation (Euler)** | $D_x f$           | $D_y f$                                     |

f'(x) => f of x behaves like a straight line having a slope f'(x)
